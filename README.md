# 🇮🇳 Apex Horizon Public School - Indian School Management System (K-10 Model)

A modern, responsive, zero-dependency **School Management System (SMS)** tailored specifically for the **Indian School Education Framework (CBSE / State Board)** spanning from **Playgroup to 10th Standard**.

---

## 🏫 Indian Schooling Structure (Playgroup to Class 10th)

The application models the Indian K-10 educational continuum:

| Stage | Classes Covered | Focus & Curriculum |
| :--- | :--- | :--- |
| **Foundational Stage (Pre-School)** | **Playgroup, Nursery, LKG, UKG** | Early phonics, rhymes, numbers, cognitive play, gross motor skills |
| **Primary Stage** | **Class 1, Class 2** | English, Hindi, Mathematics, Environmental Studies (EVS), Art |
| **Preparatory Stage** | **Class 3, Class 4, Class 5** | English, Hindi, Mathematics, General Science, Social Studies, Computer |
| **Middle Stage** | **Class 6, Class 7, Class 8** | Languages (Eng, Hin, Sanskrit), Math, Science, Social Science, IT |
| **Secondary Stage (Board Exams)** | **Class 9, Class 10 (10-A, 10-B)** | CBSE 10th Board Exam Curriculum (Science, Math, SST, Eng, Hindi, AI & IT) |

---

## 🌟 Key Features

### 1. 🛡️ 4-in-1 Role Portals & Dynamic Switcher
- **Administrator Portal**: Oversees 15 classes from Playgroup to 10th, faculty staff (PGT, TGT, PRT, NTT), fee collection in **INR (₹)** with UPI/NEFT tracking, and CBSE board registration circulars.
- **Teacher Portal**: Class agenda for mentors (e.g. Sunita Sharma - Class 10-A Mentor), daily morning assembly roll call, and internal assessment evaluation.
- **Student Portal**: Daily Indian school schedule (08:00 AM - 02:00 PM), attendance percentage, CBSE grade breakdown, and **1-Click Official CBSE Report Card Download**.
- **Parent Portal**: Real-time child campus check-in, Quarterly composite fee ledger in ₹, and **1-Click Tax Invoice / Fee Receipt Download**.

### 2. 📄 CBSE 9-Point Grading Report Card & Fee Receipt Generator
- **Official Progress Report Cards**:
  - Affiliation to CBSE, New Delhi (Affiliation No. 2130849, School Code: 71204, UDISE+: 07010200301).
  - Scholastic assessment with CBSE 9-point scale: **A1 (91-100), A2 (81-90), B1 (71-80), B2 (61-70), C1 (51-60), C2 (41-50), D (33-40 Pass), E (Essential Repeat)**.
  - Co-Scholastic Grades: Work Education, Art Education, Health & Physical Education, Discipline (Grade A/B/C).
  - Student details: Roll No, Admission No, Student PEN (Permanent Education Number), Father's Name, Mother's Name.
- **Official Fee Receipts & Tax Invoices**:
  - Itemized breakdown in **INR (₹)**: Tuition Fee, Atal Tinkering Lab (ATL) Fund, Smart Class Levy, Development & Exam Fund, Bus Transport Fee.
  - Payment modes: UPI (GooglePay / PhonePe / BHIM), NEFT / RTGS, POS Debit Card, Cash, Cheque.
  - Valid for Income Tax Section 80C tuition rebate claims.

### 3. 📅 Daily Attendance & Roll Call
- Class and section selector with Indian date format (`DD/MM/YYYY`).
- Quick status toggles: **[P] Present in Assembly**, **[A] Absent**, **[L] Late Arrival**, **[E] Excused Leave**.

### 4. ⏰ Weekly Indian School Timetable (08:00 AM - 02:00 PM)
- 7 periods per day + morning assembly + zero period + recess.
- Automated faculty conflict detection.

### 5. 📢 Noticeboard & Circulars
- CBSE Board LOC Registration verification for Class 10.
- Parent-Teacher Meetings (PTM) scheduling.
- Half-Yearly / Periodic Assessment datesheets.
- Inter-House Athletic & Yoga Championship (Shivaji, Tagore, Ashoka, Raman Houses).
- Festive holiday advisories (Diwali, Chhath Puja, Independence Day).

## 🚀 How to Run

### Method 1: 1-Click Batch File
Double-click `start_app.bat` inside the project folder. It will launch the local HTTP server and open `http://localhost:8080` in your browser.

### Method 2: Direct Browser Open
Double-click `index.html` to open directly in Chrome, Edge, or Firefox.
